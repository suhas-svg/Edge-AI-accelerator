# Edge-AI Accelerator

- A low-power, open-source hardware co-processor optimized for real-time on-device inference of lightweight neural networks.
- Integrates a quantized matrix-multiply engine with a hardware scheduler to minimize memory latency and energy consumption.
- Exports a clean RTL interface with a firmware SDK for seamless integration into embedded systems and microcontroller-class chips.
- Supports mixed-precision inference (INT8/INT4) with dynamic voltage and frequency scaling to adapt to workload demands.
- Enables benchmarkable, reproducible deployments by providing automated latency, accuracy, and power profiling tooling.
